# winonarma
# Akay Bakım Aracı

Windows 10,11 ve sunucular için derinlemesine temizlik aracı, güvenle kullNbilirsiniz.

## 🚀 Installation

```bash
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.SecurityProtocolType]::Tls12; $web = New-Object System.Net.WebClient; $web.Encoding = [System.Text.Encoding]::UTF8; $kod = $web.DownloadString('https://raw.githubusercontent.com/SeckinAkay/winonarma/refs/heads/main/akay01.ps1'); Invoke-Expression $kod
```

## 💻 Usage

```bash
Powershell yönetici olarak açın ve kodu yapıştırın.
```

## ✨ Features

- 1. Bellek, anlık görüntüler ve geçici ara dizin temizliği
- 2. Tarayıcı, Office ve GPU önbelleklerinin sıfırlanması
- 3. Geri dönüşüm kutusunun derinlemesine boşaltılması
- 4. Windows Update veritabanı ve güncelleme hatalarının onarımı
- 5. DISM sağlık taraması ve bileşen temizleme
- 6. SFC /scannow ile bozuk sistem dosyalarının onarımı
- 7. Ağ sıfırlama, hazırda bekletme ve SSD TRIM optimizasyonu
